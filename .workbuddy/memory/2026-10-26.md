  refs/remotes 下所有引用都没了（目录都消失）；`git update-ref` 与 `git fetch` 都报成功创建但引用瞬间消失（exit 0 不落地）。
  **最终根因两层**：① 有进程在清 loose refs（与「并发 git 工具冲突清空 refs」前科同类）；② 我手工补写时
  PS 5.1 的 `WriteAllLines`/`Set-Content` 默认 **CRLF 行尾**——loose ref 容忍（解析时剥空白），**packed-refs 不容忍**
  （`\r` 被并进引用名，git 报 `ignoring ref with broken name refs/remotes/origin/main?` 静默忽略整条）。
  **正解：写 packed-refs 必须用 `[System.IO.File]::WriteAllText` + `` `n ``（LF）**。修复后多轮 git 命令验证稳定。
  后续遇到 [gone]：先 `ls-remote` 核实远端 → 看引用文件/目录是否还在 → 手工写时必须 LF →
  `git for-each-ref` 若报 broken name `?` 结尾就是 CRLF 没剥干净。
