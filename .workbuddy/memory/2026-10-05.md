## serve 后台实例"无声退出"——真凶定案

- 对照实验推翻了 present_files 假设：不打开预览的实例照样 35 分钟死（exit 1、零输出、
  事件日志无崩溃记录）。4 次死亡（2m37s/31m/35m/48m）共同点只有一个：**都是 agent 会话
  里 `run_in_background` 起的**；今早用户自己终端起的实例活了 8 小时+。
- `Start-Process` 分离进程两条路都被宿主拦死：沙箱内秒死（日志空）、加
  `dangerouslyDisableSandbox` 也 PassThru 返回空、进程不出现。
- **结论：宿主对 agent 会话的常驻进程有回收机制，且禁止脱离进程树。要长驻服务，给用户
  一行命令让他自己起：`pnpm run dev:serve`（项目里已有此 script）。**
- serve 日志留痕方案保留：`serve 2>&1 | Out-File serve.log`（`~/.nx-kn/serve.log`，
  另有 serve.out.log / serve.err.log 为分离尝试的空文件，可删）。
