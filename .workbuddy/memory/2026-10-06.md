## 检索结果关键词标黄（面板）

- 需求：检索命中的关键词标黄。实现走**前端自算**，不走 zg 原生高亮——查过
  `@zvec/zvec-grep/dist/cli/format/highlight.js`：`shouldUseColor()` 只在 TTY /
  `--color=always` 下开、输出 ANSI（`\x1b[1;33m`），我们经管道 spawn 拿到的是纯文本；
  且它的 `highlightTerms()` 中文部分只把**整句**作为一个 term，中文问句一个字都标不出来。
- 新增 `src/web/frontend/highlight.js`（纯函数、零依赖）：`highlightTerms(query)` +
  `splitHighlight(text, query)`。规则：英文/数字整词（允许内部 `-`/`.`，停用词表抄 zg 的）、
  中文按 **2-gram**、停用词（什么/怎么/how/the…）不标。匹配用 `indexOf` 不用 RegExp
  （问句含 `(` `*` `.` 是常态，当正则会抛异常或误匹配）。相邻 bigram 的重叠区间合并 → 整词块。
- **为什么放 web/frontend 而不是 core**：`consistency.test.mjs` 的「view.jsx 只 import
  前端壳与 react」正则 + eslint 前端块 `**/core/**` 禁列，双闸禁止 view.jsx 引 core。
- 渲染：`components/ui.jsx` 新增 `<Highlight text query />`（输出 `<mark className="hl">`）；
  kb/view.jsx 的 snippet 与 heading 接入。tokens.css 加 `--hl-bg: #ffe58f` /`--hl-ink`
  （面板里除 `--bad` 外的唯一彩色，注释写明是「检索命中」不是装饰）；style.css base 层加
  `mark.hl` 规则（放 base 而非某个 style 策略：黄=命中要跨风格一致）。
- 结果计数行加「黄底 = 字面命中」——语义召回字面不重合时没有黄块，避免被当成 bug。
- 验证：`tests/unit/highlight.test.mjs` 12 条；全量 unit 100/100、lint 0、build 通过。
  serve 无需重启（静态文件按请求读盘）：请求 127.0.0.1:7881 拿到的 index.html 已引用
  新构建 assets（index-BmUDO3SN.js / index-CyyQROYo.css），刷新页面即生效。
