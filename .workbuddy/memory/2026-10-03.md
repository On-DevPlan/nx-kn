## 改了什么（5 处 CSS + 1 处视图）

1. **`tokens.css`：`--mid` `#8b9096` → `#6a6f76`**（3.22:1 → 5.06:1）。它是唯一的
   「次要文字」色，被 11 处样式引用（dt/.tab/.row .desc/.tag/.cli-hint/brand .sub/
   .muted/.empty/按钮禁用态）。**注意 dark 主题的 `--mid` 是 5.47:1，合格，别一起改。**
2. **`style.css` 补 `.opt-row` / `.opt-label` / `.opt-actions`** —— 模板只有类名没有样式，
   `form` 是 `display:block`，input 退回浏览器默认宽 151px（实测），补齐后 1324px。
   settings 视图同款类名一并修好。
3. **`style.css`：`input { color: var(--ink) }` + `input::placeholder { color: var(--mid) }`**
   —— 原本落到 UA 默认 `#545454` / `#757575`，与 token 体系脱节。
4. **`row.css` 新增 `.row.wrap` 变体**：`.row` 固定 28px 高 + `.desc` 的 nowrap/ellipsis，
   多行片段被压到相邻行上叠字。变体改 `height:auto` + `flex-wrap` + `.desc` 独占第二行。
5. **`snippet-box.css`：`color: var(--ink)`** —— 片段是内容不是注脚，不继承 `.desc` 的灰。
6. **`kb/view.jsx` 加加载态**：`/api/kb/status` 冷启动实测 5.9–6.5s（zg status 子进程），
   期间面板已把 `st === null` 渲成「未设定 / zg 未安装 / 未建」——**把「还不知道」说成
   「就是没有」**。改为显示 `…`。
7. `cli-hint.css` 补 `.cli-hint-flag { color: var(--ink) }`。
